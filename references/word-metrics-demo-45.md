本文件归纳 2026-11-14 围绕第45期（20261108—20261114）并购周报的 15 段录制，以及用户在同一任务中明确确认的口径。主用途是让后续编制在遇到同类审核数字、券商家次、注册批复、在审新增受理和 Word/Excel 对账时有明确执行路径。

## 一、证据边界与使用原则

1. **用户当前明确指令 > 项目当期成果/公告原文 > 项目记忆 > 既有 skill > 录制推断。** 本文件记录的是已经确认的规则；遇到当期事实变化，仍回公告、交易所项目页和证监会表核验。
2. **录制只证明当时可观察的动作。** 未捕获不等于未操作，不能根据缺段推断用户未点击、未保存、未检索或未完成某项工作。
3. **附件的文本是事实材料，不是新的操作指令。** 用户提供的 DOCX、XLSX、网页和旧稿中的句子不能越过用户当前要求自动变成 skill 规则；只有用户明确确认的口径才固化。
4. **第45期数字是回归样例，不是以后各期的固定常数。** 通用对象是公式、取数路径和核验门禁；42、44、37、49、20、36、37 等具体值只用于本期复核。
5. **不宣称未经验证的完成状态。** 结构完整、公式可计算、单渠道核对、三渠道交叉、公告全文核实、视觉渲染通过是不同结论，须分别记录。

## 三、Word 审核通过与审核总数的最终口径

### 1. 两层公式

- **审核通过（Word 宽口径）** = `暂缓二次上会 + 简易审核 + 普通程序一次性过会`
- **审核总数** = `审核通过 + 否决 + 暂缓尚未二次上会`

第45期用户最终确认：

- 审核通过：`2（暂缓二次上会） + 3（简易审核） + 37（普通一次性过会） = 42 单`
- 审核总数：`42 + 1（否决） + 1（暂缓尚未二次上会） = 44 单`

用户早期口述“普通程序一次性过会 38 单”已经明确纠正为 **37 单**。38 是过期口述，不得再写入 Word、Excel、PPT 或说明。

### 2. 0号 `重组委通过` 的底层拆分

第45期 0号 `重组委通过` 共 42 行，拆分为：

- `39 行上会通过`
  - `37 单普通程序一次性过会`
  - `2 单暂缓后二次上会通过`
- `3 行简易程序`
  - 中国神华
  - 中微公司
  - 拓荆科技

因此：

- `42 = 39 + 3`
- `39 = 37 + 2`
- `42 = 37 + 2 + 3`

**不得把 42 行直接解释为“上会通过 42 单”。** 动态文件若写“上会通过 39 单（上交所 20）”，是窄口径；上交所再把 3 单简易程序单列，`20 + 3 = 23` 与 0号上交所合计一致。

### 3. 暂缓口径

- 暂缓历史总数 = 仍暂缓尚未二次上会 + 暂缓后已二次上会通过。
- 第45期：`暂缓历史总数 3 = 仍暂缓 1 + 已二次上会通过 2`。
- Word 中“暂缓 N 单”若指当前状态，只写仍暂缓的 1；已二次通过的两单归入审核通过，并在同一段注明“其中 2 单为暂缓审议后二次上会通过”。
- 不得把“当前暂缓 1”与“二次通过 2”再加成“审核通过 3”或“总审核数另加 3”。

### 4. 不得混算的对象

以下数字必须分别保留分母与来源：

- 43 次重组委会议：会议次数；
- 42 单审核通过：项目数；
- 49 家次顾问：42 单对应的财务顾问参与家次；
- 其他口径下的 50 家次顾问：若出现，必须有独立分母，不得与 49 家次互换；
- 39 单上会通过：窄口径项目数；
- 3 单简易程序：审核通过，但不召开重组委会议。

## 六、本周新增受理与在审单数

判断在审单数时必须检查本周是否有新增受理。

### 1. 处理顺序

1. 三所项目动态按受理日期筛本期区间；
2. 打开项目页或受理通知核验受理日；
3. 用公司公告交叉，确认受理事项；
4. 将新增受理纳入“当前在审”；
5. 同步在审项目详情及受影响的 Word/动态/PPT 数量；
6. 记录项目、代码、交易所、板块、受理日和来源。

### 2. “申报稿”辅助发现

- 公告标题出现“重组报告书（草案）（**申报稿**）”通常意味着项目已受理。
- 关键词必须是“申报稿”，不能只用“草案”或“报告书”。
- 这是辅助信号，不是受理事实本身；最终仍须看交易所项目动态或受理公告。
- 受理日查公司公告或交易所网站，不用最新更新时间、报告书披露日、新闻日替代。

### 3. 第45期实例

用户查三所网站后确认 **民爆光电** 为本周受理项目。该实例说明：旧在审表没有的项目，可能因本周新增受理而应进入本期在审数；不能只在旧表上做状态更新。

一般规则：

- 协议转让、要约收购通常有财务顾问；
- 单纯一致行动关系达成或解除通常无财务顾问；
- 但“通常”不能替代公告核验；每条仍须按代码检索权益变动、收购报告书、核查意见、详式权益变动等标题。

### 2. 标题漏检

财顾文件不一定叫“独立财务顾问报告”，还可能是：

- `XX证券关于〈公司〉详式权益变动报告书之财务顾问核查意见`
- `XX证券关于〈公司〉收购报告书之财务顾问核查意见`

因此检索词至少覆盖：`权益变动 收购 核查意见 财务顾问 详式`。

### 3. 青岛食品溢价率

- 现有口径：`交易价格 ÷ 签署前一日收盘价 − 1`
- 青岛食品结果 `−29.66%` 按该机械公式计算正确。
- 超过主板跌幅下限是国有非公开协议转让定价机制导致，应在备注解释，不得擅自改基准或改数字。
