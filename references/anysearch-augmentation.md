# AnySearch 线索发现层（v4.5.17 增设）

本文件定义 AnySearch 在并购周报中的**唯一合法定位：线索发现层（lead layer）**。它是既有「搜索引擎及媒体可找线索，不能单凭摘要定事实」（见 [search.md](search.md) 第 18 行）这条规则的实例化，不新建事实定案通道，不改证据台账结构，不改 `auto_run.py`。

## 1. 定位与边界（硬性）

| 维度 | 规定 |
|---|---|
| 层级 | 第 0 层「线索发现」，位于官方源检索之前或与官方源并行 |
| 产物 | 候选清单（公司名 / 证券代码 / 公告标题 / URL / request_id） |
| 证据地位 | **不构成证据**。AnySearch 返回的标题、摘要、转载站正文一律不进 `event-ledger.json` 的 `sources[]`，不进 Excel 任何单元格，不写进《编制与待核说明》的结论段 |
| 定案路径 | 命中后必须回官方原文（巨潮 `cninfo.com.cn` / 三所 / 证监会）取得完整公告 PDF，读正文核验，再按既有规则入台账、入表 |
| 覆盖状态 | 单列 `ANYSEARCH_LEAD`，**不计入** `COMPLETE / PARTIAL / LIMITED` 三档的判定；官方源覆盖不足时仍按既有口径记 `PARTIAL / LIMITED` |
| 零新增结论 | 禁止以 AnySearch 零命中或少量命中推导「本周无新增」；零新增只按 [review-demo-part4.md](review-demo-part4.md) 与 [search.md](search.md)「零结果兜底」的官方源证据链判定 |
| 主链路脚本 | **不接入** `acquire_sources.py` / `auto_run.py`。该脚本是纯标准库直连官方入口，凭证与第三方依赖会破坏已冻结的盲测回放哈希与 `--offline` 语义 |

理由：第 45 期九次失误的共同根因是「该取证的地方凭推断」（见 SKILL.md「复核铁律」）。AnySearch 是第三方聚合索引，其摘要属于「推断级」材料，把它升格为事实来源等于把已固化的教训重新引入。

## 2. 已实测有效：防漏检补充召回（2026-11-18 证据）

AnySearch 用自然语言长尾 query 可直接命中官方公告 PDF 直链，对 skill 内已记录的两类漏检有效。以下为当日实测，回归样例，不是以后各期的固定目标。

### 2.1 中远通式漏检（控制权检索组长尾召回）

[search.md](search.md)「控制权变更必查检索词」记录：中远通 301516 的标题骨架是「一致行动人协议到期不续签 + 新签一致行动人协议 + 实际控制人拟变更」，不含「控制权变更」「协议转让」「详式权益变动」，2026-11-12 曾整笔漏检，后来靠 17 组关键词交叉才捞出。

实测单次 query：

```
一致行动人协议到期不续签 实际控制人拟变更 提示性公告 2026
```

首条即命中官方原文：

- `http://static.cninfo.com.cn/finalpage/2026-11-11/1225667423.PDF`
  —— 「深圳市核达中远通电源技术股份有限公司关于一致行动人协议到期不续签及部分股东签订新的一致行动人协议暨公司控股股东、实际控制人拟变更的提示性公告」

同一批另两条命中凤凰网、搜狐转载，可作线索，不作定案。

**执行规则**：控制权 17 组必查词（`控制权变更`、`控制权`、`实际控制人`、`实际控制人变更`、`控股股东`、`一致行动人`、`一致行动协议`、`简式权益变动`、`详式权益变动`、`权益变动报告书`、`收购报告书`、`要约收购`、`表决权委托`、`无偿划转`、`司法拍卖`、`间接转让`、`重整`）之外，每期另跑下列 5 组长尾自然语言 query，用 `anysearch_batch_search` 一次并发：

| # | query |
|---|---|
| 1 | `一致行动人协议到期不续签 实际控制人拟变更 提示性公告 <年度>` |
| 2 | `解除一致行动协议 实际控制人拟发生变更 提示性公告 <年度>` |
| 3 | `表决权委托 无偿划转 控股股东变更 提示性公告 <年度>` |
| 4 | `要约收购报告书 收购报告书 控制权变更 <年度>` |
| 5 | `简式权益变动报告书 协议转让 第二大股东 <年度>` |

命中结果按「公告有、底表无」与「底表有、字段残缺」两类清单回原文判定，与 [search.md](search.md) 第 89—90 行的双向核对合并执行。缺任一组仍记 `PARTIAL`，**AnySearch 全命中不豁免官方源 17 组**。

#### 5 组全量实测与召回质量校准（2026-11-18 复测）

一次 `anysearch_batch_search` 并发 5 组，5/5 成功，但**召回质量分三档**，不得把「有结果」等同于「有效线索」：

| 组 | 有效命中 | 噪声 | 判定 |
|---|---|---|---|
| 1 | 中远通 301516 官方公告 PDF `1225667423.PDF` | 凤凰网/搜狐转载 | **A：直接可用于定位原文** |
| 2 | 铁大科技 920541「解除一致行动人协议及实际控制人变更暨权益变动的提示性公告」、巨能股份 920578 | 律所文章 | **A** —— 且**跨期召回**（铁大科技 2026-07-10，非本期），说明本层不自带本期区间过滤 |
| 3 | 亚泰集团 600881 无偿划转、信息发展 300469 解除表决权委托、富奥股份 | 上交所《股票上市规则》条文（错配） | **B：需人工筛** |
| 4 | 真爱美家要约收购报告书 PDF | 2007 年旧规、康达尔旧案例、现行《收购管理办法》条文 | **C：噪声为主**，长尾 query 把法规条文也召回 |
| 5 | 凯撒文化 1225650564.PDF、南方卫材、立航科技、协和电子简式权益变动报告书 | 少量 | **B** —— 都是报告书原文，但**均未标注是否成为第二大股东**，13 号判据须逐份读正文比较变动后持股排序 |

两条校准结论（硬性）：

1. **本层不自带本期区间过滤**。第 2 组返回 2026-07-10 的铁大科技，第 4 组返回 2007 年征求意见稿。所有命中必须按公告日／会议日／终止审核日回落到本期区间，**跨期命中只登记为「存量项目线索」，不进本期新增**。
2. **法规条文命中一律剔除**。第 3、4 组把《股票上市规则》《上市公司收购管理办法》条文召回，属检索噪声，不进政策口径、不进检索台账结论；政策检索仍走证监会／三所／见微法规库。

**官方源反查验证（同日）**：把第 1、2 组命中回见微公告库核验，均取得带命中页码的官方原文，证明「线索→定案」路径可行且必要：

- 中远通 301516，2026-11-11，公告编号 2026-053，「关于一致行动人协议到期不续签及部分股东签订新的一致行动人协议暨公司控股股东、实际控制人拟变更的提示性公告」 → [原文](https://static.cninfo.com.cn/finalpage/2026-11-11/1225667423.PDF) ｜ [详情](https://www.jianweidata.com/FilingDetail?key=WAQKtBdMNlN3zT2xTKy0S/g18LjC9e1kFeB2ypPnuAFkJNl+wDX9Zw==&sector=1&nm=0&cm=%E5%AE%9E%E9%99%85%E6%8E%A7%E5%88%B6%E4%BA%BA&cs=)
- 铁大科技 920541，2026-07-10，公告编号 2026-055，「关于解除一致行动人协议及实际控制人变更暨权益变动的提示性公告」 → [原文](https://www.bse.cn/disclosure/2026/2026-07-10/cf4c36614eac4856b65d5c909aef8f6d.pdf) ｜ [详情](https://www.jianweidata.com/FilingDetail?key=/lcFYSb+StH9QCsiclNYcmcAY9MDstVdtaHiO4x4o9D45lCNIk9amQ==&sector=1&nm=0&cm=%E4%B8%80%E8%87%B4%E8%A1%8C%E5%8A%A8&cs=)

### 2.2 巨能股份式漏检（北交所标的）

[search.md](search.md)「巨潮检索：北交所必须用公司名称检索」记录：巨能股份 920578 用代码检索巨潮 0 条、`bse.cn` 直链 302 循环，曾误判「无法取得」，改用公司简称后取得 4 条公告、转让价款 7,927.5 万元、每股 17.50 元、受让方宁夏共享集团。

实测单次 query：

```
巨能股份 920578 转让对价 受让方 宁夏共享集团
```

命中东方财富行情页（含「共享集团拟受让453万股」「控股股东拟变更为宁夏共享集团」）、证券之星详式权益变动报告书、中财网解除一致行动协议公告。

**执行规则**：北交所标的（920 / 历史 8 / 4 代码）在既有四级降级通道之外，可先跑一组 `公司名称 + 代码 + 目标字段` 的自然语言 query 定位公告载体；定位到 `static.cninfo.com.cn` / `stockstar.com` 等链接后，**仍回巨潮按公司简称取 PDF 正文**。AnySearch 命中只用于缩小范围，转让对价、每股价格、受让方全称、股比一律取公告原文。

## 3. 已实测有效：字段缺口的备用取数通道

行情类字段（`「<首次披露年>年首次披露」` sheet 的 `股份转让协议签署前一日收盘价`、`股份转让协议签署前一日上市公司市值（亿元）`、`股份转让协议溢价率`）既有口径是 Wind 或同花顺 MCP。AnySearch 可作**交叉验证通道**，不作定案通道。

实测（2026-11-18）：

| query | 结果 | 可用性 |
|---|---|---|
| `青岛食品 控制权变更 协议转让 溢价率 收盘价` | 命中新浪公告页，含「转让总价 965,000,000.00 元，16.9246 元/股」 | 线索级；定价依据《上市公司国有股权监督管理办法》须回公告原文 |
| `天汽模 002510 申万行业 分类 汽车模具` | 命中新浪/搜狐/东财行业页，摘要未给出申万四级分类 | **不足**，行业分类按 [wind-industry.md](wind-industry.md) 取 Wind，禁用 `待核` |
| `tag=finance.quote, params={type:stock,cn_code:002510.SZ,period:7d}` | `$5.76 / 7d High 6.30 Low 5.71`，耗时 9.2s | 第三方聚合口径，与 Wind/同花顺可能不一致，**仅作差异提示** |

`tag` 必须取 `anysearch_capabilities` 返回的精确子域（`finance.quote`、`finance.fundamental`、`finance.news`、`finance.macro` 等）；写顶层域名（如 `finance`）返回 HTTP 400 `Invalid tag`。通用搜索不传 tag。垂直域对 A 股常降级为网页链接而非结构化字段，遇降级即停止依赖该通道。

## 5. 检索台账留痕格式

每期在检索台账新增 `anysearch_leads` 段，与既有 `coverage` 并列，字段如下：

```json
{
  "anysearch_leads": [{
    "group": "control_longtail_1",
    "query": "一致行动人协议到期不续签 实际控制人拟变更 提示性公告 2026",
    "request_id": "e275460b10a149c4a281490fa8ba395c",
    "auth": "credential",
    "result_count": 4,
    "hits": [{"title": "...", "url": "http://static.cninfo.com.cn/finalpage/...PDF"}],
    "recall_grade": "A",
    "in_period": true,
    "official_source_resolved": true,
    "official_source_locator": "巨潮 hisAnnouncement/query 按公司简称；PDF 第 1 页",
    "official_source_files": ["1225667423.PDF 提示性公告", "1225667424.PDF 长江保荐核查意见"],
    "ledger_case_ids": ["issuer-301516-control-2026"],
    "note": "线索级，不作定案"
  }],
  "coverage": [{"group": "ANYSEARCH_LEAD", "status": "NOT_APPLICABLE", "evidence": "线索层，不参与覆盖判定"}]
}
```

字段约束（硬性）：

- `request_id` 必填，便于向上游追溯；`auth` 记 `credential` / `anonymous`。
- `recall_grade` 必填，取 `A`（直接命中官方公告原文）／`B`（命中原文但需人工筛或字段不足）／`C`（噪声为主）三档，按第 2.1 节实测校准表判定。
- `in_period` 必填。本层不自带本期区间过滤；`false` 的命中只登记为「存量项目线索」，**不进本期新增**，并在 `note` 写明实际公告日。
- `official_source_files` 必填数组：官方源取回的**全部**配套文件，不只线索层命中的那一篇。实测中远通除提示性公告外另有长江保荐核查意见，缺一即 `official_source_resolved=false`。
- 法规条文、旧规、转载站一律记 `recall_grade=C` 且 `official_source_resolved=false`，不进政策口径。
- `official_source_resolved=false` 的线索列入 `pending-review.json`，不得静默丢弃。

## 6. 与无人值守主链路的关系

`auto_run.py --as-of YYYY-MM-DD` 的 ACQUIRE 阶段只读官方源，凭证与第三方索引不进入该阶段。本层由**人工逐步复核 / 诊断性编制**时使用，可在「锁定本期范围」之后、「检索并建立证据台账」之前手工执行一批并发 query，把命中并入既有的候选并集。

`--offline` 结构回放时本层全记 `NOT_RUN`，不得因缺少 AnySearch 把官方源覆盖矩阵降级。

## 7. 配额与并发

- 账号额度 1,000 次/日、10 QPS，每日 08:00（北京时间）重置，不累积；同账号多 key 共享额度。
- `anysearch_batch_search` 单次 1—5 个独立请求，单个失败不影响其他；控制权 5 组长尾 query 一次批量即可。
- 通用搜索约 1.1—1.5s，垂直域约 9—11s，批量总耗时取最慢一条。
- 凭证引用名为 `ANYSEARCH_API_KEY`，由 DSH 凭据管理逐次解析；**不写进命令、脚本、日志、Git 或本文件**。

## 8. 与既有规则冲突时的优先级

1. 公告原文 / 官方源（巨潮、三所、证监会）为事实定案依据。
2. 既有「先验工具、再信结论」「复核先读回、再取证、后改动」「单元格只写事实」等铁律不变。
3. 本层仅在「发现候选」这一环节补充召回，不覆盖任何既有必查词组、不降低覆盖标准、不改写零新增证据链。
