# Wind四级行业查询与回填

## 已验证路径（2026-11-11）

使用已配置Wind MCP的 `market_search_tools` 搜索“股票基本资料、Wind行业分类、一级至四级行业”。检索结果返回 `securities_get_profile`，其参数是单个 `windCode`（含市场后缀）。再调用 `market_call_tool`：

```json
{"toolName":"securities_get_profile","arguments":"{\"windCode\":\"600500.SH\"}"}
```

工具名称及参数应以当时搜索返回的契约为准。不要将本次接口名当作永不变化的依赖。先查询第一个标的确认身份及成功结果，再串行查询其余标的。

解析返回内容中的 `windCode` 与 `items`，只取 `name` 为“所属Wind行业”的 `value`。按 `--` 分开的四层依次为一级、二级、三级、四级。保留“Ⅲ”等字符原样，不用主题行业、国民经济行业或中上协行业替代。返回缺层级时不得自行补足成数据库原值。

原生MCP工具尚未在当前聊天暴露时，可通过已配置的Wind HTTP MCP端点执行同样的JSON-RPC查询，不必反复要求重启；认证从用户本机配置安全读取，不在脚本、项目、skill或日志写入密钥。Streamable HTTP响应须按UTF-8解析；SSE数据跨行时组装完整事件后再解析JSON，不能把第一行的截断JSON当成服务失败。后端认证、额度或网络失败按原错误处理，不以常识代填。

## 回填与范围

- 按股票代码与公司名定位行，按表头定位“上市公司wind至四级行业”，写入完整四级链，并在工作底稿记录工具、代码、查询日、原始返回值及requestId。
- 上市公司与标的公司是不同主体；不能因为同属某行业，将上市公司的Wind分类直接填进标的行业栏。非上市标的需独立取证，没有数据库原值的字段继续标待核。
- 值已一致时只记录“Wind已核验”，不制造数据变动；有实质变动的格子才标绿。续填本期副本不重新清除已有本期绿色。
- 同步撤销已解决的待核提示，但只撤销该字段；保留尚未解决的标的行业提示。另存新版，复读核对字段、格式及其他sheet未变。
- 当前基础资料返回的是查询时点分类，不能据此宣称已取得历史截止日行业快照；如要求历史分类须另找支持对应日期的工具。

本次实测返回（仅作测试记录，不作未来交易的硬编码）：中化国际600500.SH为“材料--化工--多元化工Ⅲ--其他多元化工”；海南矿业601969.SH为“材料--有色金属--其他金属与采矿--金属非金属”。两条上市公司查询成功不代表南通星辰或丰瑞氟业的Wind分类已独立核验。
