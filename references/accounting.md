# 统计口径及字段语义

## 日期、交易与年度

- `deal_id` 稳定标识一项经济交易；证券代码＋标的/方案身份＋首次方案日期可辅助建键。最新公告日不能作为交易唯一键。改名、换代码、原项目终止后另起方案须留映射与判断依据。
- 事件去重用交易＋事件类型＋实际事件身份；同一事件多份公告共用事件，留多个来源。多标的拆行、联合财顾、公告修订不能增加交易单数。
- 首次方案：`预案`是 `first_disclosed`；无预案直接披露 `报告书（草案）`是 `first_draft`。首次草案独立保存；修订稿、财顾首次披露不是重新首次披露。仅停牌、筹划、预挂牌或框架意向是 `lead_signal`，不纳入方案首次数但保留跟踪。
- 委员会过会采用会议日；注册、方案、控制权完成采用经核实的正式公告日（源自手册）。注册签发/收到批复及过户、工商登记、董事会改组的实际日期另列，不互相替换。IPO终止用现行表头及期报采用的终止决定/公告口径锁定，并保留两种日期。
- 同一交易首次在预案/草案、随后获得受理、问询、回复、过会、注册、终止时，只在同一交易行更新状态；后续事件不得创建新的首次披露行。
- 复合的现金购买及出售在一个交易下保留两个方向，分别写入购买/出售专表；市场项目总数按证券代码或交易指纹去重。
- 本周事件与本年累计事件按各自日期区间去重筛选；历史年度首次库继续跟踪，不因改名、终止或年末清空历史记录。
- 截止日存量按该日前已可知事件重建。不能用截止日以后的更正或结果倒改当期结论；必要时另列后续更新。受理与进入问询是不同事件。
- 年度累计与截止日存量须从更新后的基础工作簿重新勾稽；本周事件台账只能给出周增量，不能冒充年度累计或在审总数。第43期工作簿“是否在审=是”为48单，正文曾写49单，属于应在交付前暴露的内部差异。
- 终止事实与“在审终止”分开：方案披露前/筹划阶段终止可进入终止明细，但不得从在审存量扣减；进入在审须有受理事件或基础工作簿状态支撑。

## 在审、上会及通过

第42/43期模板定义：在审不含已经重组委通过、提交注册、注册生效及终止/撤回；包含受理、问询、已回复、恢复及中止的未通过项目。审核状态与“是否在审”分列。未受理预案是筹划/已披露待申报，不能因2022旧笔记而计入当前在审。被否/重新受理等特殊状态回交易所过程核实，不能按旧枚举直接推。

同时保留：
- 会议场次：交易所＋会议年度＋届次；场次不等于项目数。一场多个案算一场；取消会议不算已召开。
- 审议次数：包括同笔交易暂缓后再审，按实际出席会议事件计；拟审安排不算结果。
- 当年去重已审交易：年内有委员会结果的交易集合；通过/否决看约定的最终有效结果。
- 年内委员会通过交易；另列简易程序通过交易，并按模板注释决定汇总是否含简易。
- 暂缓不写为否决；简易程序无委员会场次，不人为补一场。

## 顾问与金额

- 独立财顾及一般财顾/收购方财顾分角色，已确定但未公开的不混入“已披露独立财顾”。“华泰联合，尚未披露”不能仅因包含华泰字符串计入。
- 吸并交易可能有双方顾问，按照表注记录角色；同一券商同笔同角色重复出现只计一次。券商改名的历史业务归并要有别名表和口径，不能按子串吞并不同机构。
- `项目数`、`披露财顾项目数`、`顾问家次`不同。联合财顾一单可贡献两家次。数量占比分母是顾问家次还是交易单数，必须与表头表注一致。
- 券商对应金额可按联合项目全额分别计入；市场交易金额按唯一交易只计一次。分项舍入后相加不作为未舍入合计的权威值。
- 交易作价、标的100%股权评估值、拟收购比例对应评估值、募集配套资金不能混用。未知金额须报告已知金额小计＋缺失项目数，不能把空值当0后宣称完整总额。
- 元→万元除10000；万元→亿元除10000。外币保留币种、原币单位及折算日/汇率来源，不能直接与人民币相加。符号“-”不代表0。

## 控制权与协议转让

- 公告明确实控人A→B、共同控制组合变更或有/无实控人切换才正式归类。基金/资管管理人与实际控制人的关系不能从名称推断；没有实控人的主体如实列示，不强迫写自然人。
- 记录法律持股、可支配表决权、最终控制主体与控制路径。控制比例按字段定义，不能机械把直接持股与间接表决权相加，不能把一致行动等同委托。
- 首次披露表保留 `initial_plan`，并单列/备注 `latest_plan` 和最新状态；已完成表填 `actual_completion`。阶段值不能错位。未完成不填完成日；要约交割不当然等于取得控制权，董事会改组等安排须实际满足并披露。
- 实际交易金额分笔汇总，计划上限不能当最终金额；13.33%之类少数持股取得控制权可成立，依据权利安排判断，不自设30%控制门槛。
- 12/13两表当前表头M/N均为“转让前/后上市公司实控人控制股比”。相同表头按同一经核实权利口径填写；旧skill所谓“两表M/N必然不同”的说法不直接采纳。另有新模板明确差异时以新表头为准。
- 13表要核转让后股东排序；“受让10%”不等于第二大股东。“持股差异不大”目前未量化，边界请确认，不强填阈值。
- 锁定期、交易限制、业绩对赌取实际协议及公告；不按旧skill给一律12/18个月或默认“否”。现行法律要求确需判断时另查有效原文，法规引文逐字保留。
- 收购少数股权系收购已控股子公司少数股权；不是收购任一参股公司即该类。整体上市、横向、纵向、多元化、重组上市等采用现行项目分类，不把原版五选项强套所有交易。报告书定性与内部行业判断分开。

## 估值指标（沿用手册定义，核实分母）

| 指标 | 公式/适用边界 |
|---|---|
| PE1静态 | 标的100%评估值÷基准日前一年度归母净利润；年末基准日取该当年，年中取上年。负利润不适用，0分母不算 |
| PE2动态 | 标的100%评估值÷预测期第一个完整会计年度归母净利润；手册口径年中取当年、年末取下年，核对预测表期间；仅收益法定价适用。缺预测时有明确承诺值可用并标明替代口径 |
| PB | 标的100%评估值÷同口径基准日归母净资产；零/负净资产适用性明确说明 |
| 承诺总额/覆盖 | 按各承诺期和义务人对应资产合计；承担全部对价补偿与仅自身股权义务不混。覆盖比例不同于承诺/估值 |
| 转让溢价率 | 每股转让价÷可比口径签署前收盘价−1；签署前自然日为休市日时，记录实际行情交易日及复权口径，不伪造周末成交价 |

**股份转让协议溢价率与签署前行情（2026-11-12 用户明确）**：用户原话「『2026年首次披露』sheet中，股份转让协议签署前一日收盘价、股份转让协议签署前一日上市公司市值用wind或同花顺mcp统计，『股份转让协议溢价率』用每股交易价格较协议签署前一日收盘价的溢价率」。与本表「转让溢价率」行同源：分子为每股交易（转让）价格，分母为**协议签署前一日收盘价**，溢价率 = 每股交易价格 ÷ 该收盘价 − 1；收盘价与市值（亿元）由 Wind／同花顺 MCP 取数，期间、复权与单位随值留痕。用未舍入数据复算，尾差写明；证据见 [review-demo-part2.md](review-demo-part2.md)，字段落位见 [workbooks.md](workbooks.md)。

历史模板把盈利预测、承诺或已实现利润放入同一分母列时，保留来源与替代说明；禁止无依据年化、用母公司利润代合并利润，或把亏损PE写成正常正数。
